# Antigravity 第三方模型插件

**Antigravity Third-Party Model Plugin · v1.5.2**

本次为命名与文档更新：统一中英文项目名称、GitHub 地址、横幅和下载包名称。第三方接入、模型选择、多选思考强度、配置发现和热刷新功能保持与 v1.5.1 一致。

This branding release introduces the bilingual project name, repository address, banner and package filename. Provider integration, model selection, configurable reasoning, capability discovery and live refresh retain the behavior of v1.5.1.

## 下载与安装 / Download & install

1. 下载 **antigravity-third-party-model-plugin-v1.5.2-windows-x64.zip**，可用 **SHA256SUMS.txt** 校验。
2. 完整解压，双击 **install-oneclick.cmd**。
3. 首次接入后，从 Antigravity 托盘完全退出，再正常打开一次。
4. 进入 **设置 → 模型提供商**，填写自己的 API 并选择模型。

Download and fully extract the Windows ZIP, run **install-oneclick.cmd**, then open **Settings → 模型提供商**. First-time application integration requires one full tray exit and reopen. Existing provider configuration uses the same data directory.
