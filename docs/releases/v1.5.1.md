# v1.5.1 · 首个公开发行版

第三方提供商设置、模型选择与思考档位，集成到 Antigravity Hub 的原生界面。

## 本版内容

- 设置页内管理 OpenAI 兼容、Anthropic 与 Gemini 提供商。
- 拉取可用模型后打开二级选择窗口，仅添加勾选项。
- 每个模型多选可用思考档位，聊天原生子菜单只显示选中的档位。
- 自动读取模型详情与列表元数据，按已知能力表补齐，并显示字段来源。
- 保存模型后热刷新；日常修改无需重启应用。
- Windows x64 一键安装、原始文件备份、保留配置回滚。
- 原始聊天请求抓取默认关闭；示例、截图和发行包不含用户配置或密钥。

## 下载与安装

1. 下载本版本附件 **agy-bridge-v1.5.1-windows-x64.zip**，可用 **SHA256SUMS.txt** 校验完整性。
2. 完整解压后双击 **install-oneclick.cmd**。缺少合适 Node.js 时，会下载官方固定版本并校验 SHA-256。
3. 首次接入后，从 Antigravity 托盘完全退出，再正常打开一次。
4. 到 **设置 → 模型提供商** 添加自己的 API；获取列表、选择模型、检查配置并保存。

## 兼容性与验证

当前桌面接入验证环境为 **Windows x64 / Antigravity Hub 2.31.2**；运行需要 Node.js 24.5+、正常的 Google 登录与网络，以及有权使用的提供商 API。

本地测试覆盖协议转换、思考集合、配置迁移、端点优先级、参数限制与配置隐私。安装器在独立临时 asar 上验证首次安装、原地升级、Unicode 路径与字节一致回滚，不操作真实应用。原生界面已实测多选保存、聊天子菜单和草稿自动配置。

这是独立社区项目；不包含 Antigravity 二进制，不伪造账号或额度。应用更新后可能需要重新适配。容量与思考能力最终由提供商端点决定。
